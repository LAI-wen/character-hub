02

三種視角

Owner · Member · Visitor

同一頁「企劃角色」，側欄導覽、可用動作、詳情面板的可編輯性都隨視角改變。視角為 Demo 切換（真實情況是每個企劃的成員身分）。

主持人 Owner
看得到全部，含「企劃管理」與待審。
  • 企劃管理區塊可見
  • 可管理任一角色的企劃連結
  • 但不可改他人的角色本體
參與者 Member
可加入／編輯自己的角色，看不到管理。
  • 無「企劃管理」
  • 只有自己的角色可編輯連結
  • 他人角色唯讀
公開預覽 Preview
頂部明示「公開頁預覽」；正式訪客走 Public Renderer。
  • 預覽橫幅 + 「看公開頁」
  • 無管理、無快速新增
  • 只顯示已通過、全唯讀

Slice 1.1 校正

Corrections
項目作法
Visitor = 公開預覽視角第三項改為「公開預覽」；進入時頂部出現橫幅，明示這是公開頁預覽，正式訪客走 Public Renderer（無側欄），並提供「看公開頁」與「結束預覽」。
Character 擁有權主持人只能管理 ProjectCharacterLink（陣營／職位／審核／限定欄位／企劃內可見性）；不可修改參與者的角色本體（名稱／外觀／圖文設定）。詳情面板明分「角色本體（由擁有者維護）」與「此企劃中的設定（依權限）」。
資料命名同步viewer.projectRoles[]、fieldValues、templateVersionId、collaborationMode、ownerUserId/ownerSummary；Project 能力拆成 visibility／collaborationMode／portalEnabled／joinPolicy／submissionsEnabled／enabledFeatures 分開使用。
企劃角色 vs 角色名冊roster.html（企劃角色）＝工作台管理，含 pending／approved／archived 與管理操作；新增 cast.html（角色名冊）＝成員／公開瀏覽，只顯 approved、無管理。共用卡片。
05

Data Gap

尚未支援 · 已同步命名
DATA GAP · viewer.projectRoles[projectId] / currentProjectMembership.role
歸屬 ProjectMembership。角色是每個企劃各自的成員身分；原型的「視角」只是當前企劃的 Demo 覆寫。需儲存；可見：本人。
DATA GAP · ProjectCharacterLink.fieldValues + templateVersionId + projectVisibility
歸屬 ProjectCharacterLink。依該企劃角色卡模板版本（templateVersionId）填寫的欄位值；projectVisibility = public／members／private。需儲存。
DATA GAP · Project 能力旗標（分開使用）
歸屬 Project，互不推論：visibility · collaborationMode · portalEnabled · joinPolicy · submissionsEnabled · enabledFeatures。公開頁看 portalEnabled、投稿看 submissionsEnabled。需儲存。
DATA GAP · character.ownerUserId（畫面用 ownerSummary）
歸屬 Character。角色本體的擁有帳號；畫面顯示衰生的 ownerSummary（你／@handle）。需儲存。

驗證情境

Try it

點下方連結可直接驗證對應情境（含長企劃名稱）。視角用側欄左下角的「視角」切換。

建立不屬於企劃的角色我的角色 →「灰」顯示「尚未加入任何企劃」；＋新角色為 Demo。 找到某企劃的企劃角色常夜國 → 企劃角色，依陣營分組、可篩 pending/archived。 改自己角色的企劃限定資料選「宵霧」→ 此企劃中的設定可編輯；本體唯讀。 主持人查看待審核角色企劃總覽 → 共創管理 → 待審核（緋）→ 投稿審核。 訪客進入公開頁預覽切「預覽」視角看橫幅，或直接開公開頁 Renderer。 角色名冊（公開瀏覽）只顯示 approved、無管理操作，與企劃角色區隔。 20 字以上企劃名稱「常夜國：永夜之章與失落的燈火記錄」測側欄與標題截斷。 切換企劃仍知道範圍星海計畫（個人企劃）→ 無共創管理，Context Header 標明範圍。

響應式：側欄在 ≤860px 收成抽屜（漢堡開關），內容網格自動降欄；已針對 360 / 390 / 1024 / 1440px 與 125% 縮放設計（字級用 px、容器 max-width + auto-fill 網格、長名稱 ellipsis）。請在實際瀏覽器縮放確認；預覽工具無法真正改視窗寬度。
