CharacterHub · Public Page Scope / Ownership 校正

個人公開頁 vs
企劃公開頁

公開頁不再只屬於企劃。新增 我的公開頁（Account scope），並把 PublicPage 的擁有權拆成 User-owned / Project-owned / User-owned Project-context 三種。不新增第二套資料模型、不接 API——以既有欄位衍生分類。

01

三種公開頁

Three ownership cases
類型由誰管理例子Scope
User-owned使用者本人個人角色頁、委託資訊、自訂頁Account · 我的公開頁
Project-owned企劃（依 action permission）企劃入口頁、世界觀條目頁、官方名冊Project · 公開展示
User-owned · Project-context角色擁有者（版型由企劃）「宵霧在常夜國中的角色頁」Account（屬使用者）· 企劃可管版型/收錄

Project-context 頁的權限分離：主持人可管理企劃版型、鎖定必要 Block、決定是否列入官方名冊、撤銷企劃資料公開授權、管理企劃內可見性；但不能修改 Character 本體、接管成員自訂文字、永久刪除成員個人頁、查看未授權的私人欄位。若企劃要官方角色頁，另建 Project-owned Official Character Page，不與成員個人頁混為一筆。

02

PublicPage 擁有權欄位

Ownership fields (derived)

交接概念。原型以既有欄位衍生 pageOwnerType / sourceType / pageOwnerId（無資料膨脹）；正式 schema 應顯式存這些欄位，並把四種角色分開：

概念說明
Page OwnerpageOwnerType: user|project + pageOwnerId。決定頁面歸誰、出現在哪個 scope。
Source Entity Owner頁面資料來源（Character / Link / Project / WorldEntry…）的擁有者——可能不是 Page Owner。
Template Owner版型擁有者。Project-context 頁＝企劃；個人頁＝使用者。
Publisher實際發布者（需 publicPage:publish）。能編 Draft ≠ 能發布。

sourceType: character | projectCharacterLink | project | worldEntry | story | commission | custom，搭配 sourceId? / projectId? / createdByUserId / templateVersionId? / visibility / currentPublishedVersionId?。

03

Route / Scope（route-specific）

Resolver by route + query

Scope Resolver 依路由定義＋query 驗證判定，不是只看參數名稱。「有 project 但無 link＝invalid」只適用 character/editor。

路由正式 RouteScope
public-pages.html/app/public-pagesaccount 我的公開頁
public-pages.html?project=:pid/app/projects/:pid/public-pagesproject 企劃公開頁
public-pages.html?mode=builder&page=:id/app/public-pages/:id/editbuilder · BuilderShell
portal.html?page=:id/p/:slugpublic · 無 Sidebar
worldview.html?project=:pid—project（有效，非僅篩選）
commissions.html?project=:pid—account（project 只是頁內篩選）
character/editor.html?project=:pid 無 link—Invalid Project Character Context

Builder 返回位置依 page ownership：User-owned → 我的公開頁；Project-owned → 企劃公開頁。不永遠回固定企劃頁。

04

清單關係

List separation
我的公開頁（Account）宵霧角色頁、望角色頁（連結常夜國·使用企劃版型）、委託資訊頁——個人擁有。Sidebar 維持 Account。 企劃公開頁（Project）企劃頁＋世界觀條目頁＝Project-owned；成員角色頁僅顯示「官方收錄狀態／版型版本／資料公開狀態／Broken binding」，Host 不擁有該頁。

對 Member-owned page，企劃端只能管理：官方收錄狀態、版型版本、企劃資料公開狀態、Broken／Missing Binding、是否需成員更新——不可讓 Host 看起來擁有該個人頁。

05

有效公開條件鏈

Visibility chain

Project-context 頁要公開顯示，需同時通過：

  • Page Access 且 Page Owner 授權 且 Character 可見 且 ProjectCharacterLink 可見 且 Project 仍允許公開 且 Template／Block visibility 且 Asset 可見。
  • 若 Link removed / 企劃改 private / 企劃撤銷資料授權 → 立即停止顯示企劃限定資料，不得用舊 Published Snapshot 洩漏；可保留 Character-only 頁，或轉未發布並提示修復。
