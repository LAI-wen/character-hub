03

Demo Session State

assets · OCDemo

由 OCData 初始化的可變動執行狀態，存 sessionStorage('ch:demo:v1')：同分頁跨頁保留、關閉分頁重設、側欄「重設 Demo 資料」一鍵還原。所有頁面讀同一份 runtime arrays（非各自複製 fixture）。不是正式 persistence、不是 Repository、不是第二套 Model。

  • 持久範圍：projects · entities(characters) · links · applications · contentSubmissions
  • CRUD：createCharacter／updateCharacter／archiveCharacter · createProject／updateProject／archiveProject · createLink／removeLink · createApplication／updateApplication
  • hydrateFromOCData() 載入時把 session 快照覆回同一組 OCData arrays · resetDemoData() 清除並重載
  • 封存＝改 status，不硬刪；archived 項目離開一般列表（myCharacters()／activeProjects()），但仍在全量資料中

05

P0 / P1 嚴重度

Cleared
P0 · Scope Bug ✓ 清零
未加入企劃的角色不再被當 Project Scope。scope 由 resolver 依 route+query 決定；?project= 無 link 時維持 account。
P1 · Integration Gap ✓ 清零
新增／編輯／封存經 OCDemo 寫入共用 runtime + sessionStorage，跨頁同步（工作台／我的角色／我的企劃／Switcher）。
P1 · Navigation Gap ✓ 清零
Account／Project 入口由 resolver 區分；character/editor 的編輯與返回連結帶正確 scope（?c= 或 ?project=&link=），不用錯誤 project 推測。
P1 · Global Tool Scope ✓ 清零
委託／身高比較固定 account scope；帶 ?project= 也不變 shell（可作頁內 filter，不改 scope）。
