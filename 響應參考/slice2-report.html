02

本體 vs 企劃限定

Character · ProjectCharacterLink

兩頁都用同一條界線切分。編輯器分成「角色本體」與「企劃限定設定」兩個區塊；詳情頁的「加入的企劃」分頁則把每個企劃連結獨立成卡。主持人能管理 link，永遠不能改別人的本體。

角色本體 · Character 擁有者維護

  • 名稱、暱稱、簡介
  • 圖設定（色票／必畫／不可畫／配件）
  • 文設定（背景／動機／說話／禁忌）
  • 個人標籤、代表圖片
  • 角色本體可見性

企劃限定設定 · Link 依權限

  • 陣營、企劃職位
  • 企劃限定背景
  • templateVersionId · fieldValues
  • 審核狀態、企劃內可見性
  • 主持人限定欄位（僅主持人可見）

05

分享視圖與裁切

Share Drawer

「分享」開啟 ShareDrawer，四種類型（一般／繪師／文手／完整可分享設定）。企劃限定資料預設「不包含」，且一次只能選一個企劃版本（projectCharacterLinkId），不會預設帶出所有企劃資料。私人企劃需符合可見性或明確授權。預覽標 Share Preview · Demo interaction only。

預設永不分享
  • 私人筆記（privateNotes，owner-only）
  • 主持人限定欄位
  • 審核紀錄
  • 未授權的企劃資料、其他企劃版本

開啟宵霧詳情 → 點「分享」 試單一企劃版本分享（只帶出選定的企劃）。

桌機與手機

Responsive

桌機（≥1080px）為三欄：左段落導覽 · 中編輯表單 · 右即時預覽，段落導覽顯示完成／未完成／未儲存點。窄於 1080px（含手機）改為：頂部角色名＋儲存狀態、編輯／預覽 Segmented Control、底部上一節／下一節／儲存；企劃版本切換在編輯區上方。不直接縮小三欄。請在實際瀏覽器以 360 / 390px 確認（預覽工具無法真正改視窗寬度）。

09

DATA GAP

新增欄位
DATA GAP · Character.detail（general / art / text / gallery）
歸屬 Character（本體）。這四個是 UI 呈現分組（presentation grouping），不暗示正式後端必須用同一包 JSON 儲存；可拆成個別欄位或子表。需 persistence；可見：依角色可見性與分享設定；可修改：僅擁有者。
DATA GAP · Character.privateNotes
歸屬 Character。私人筆記，owner-only，永不分享。需 persistence；可見：僅擁有者；可修改：僅擁有者。
DATA GAP · ShareLink（分享設定）
歸屬獨立 ShareLink entity（Character-owned），不可混入 Character 或 Link。欄位：scope（general/artist/writer/full）、visibility、顯示分頁/欄位、showOwner、單一 projectCharacterLinkId（或 includedProjectLinkIds，預設空）。需 persistence；可修改：僅擁有者。
DATA GAP · 主持人限定欄位（決策修正）
不另建 hostOnlyFields。欄位定義在 ProjectTemplateField（帶 visibility：public/members/host）；值仍存 ProjectCharacterLink.fieldValues；由 renderer 依 viewer 裁切。主持人限定欄位永不分享。
DATA GAP · ProjectCharacterLink.status + reviewMessage
歸屬 ProjectCharacterLink。status: pending / approved / rejected / archived / removed；rejected 携 reviewMessage（退回原因）。需 persistence；可見：成員；可修改：審核者（主持人）。reviewMessage 不進公開分享。
DATA GAP · completion（衍生）
分區完成度（一般／圖／文／企劃角色卡）是 UI 衍生資料，由現有欄位算出，不是使用者直接編輯的欄位、不需 persistence。
