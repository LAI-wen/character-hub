03

Account／Project 分區

Scope

我的靈感 Account

  • 尚未決定企劃（projectId 空）
  • 個人角色點子、跨企劃可重用
  • 預設 private

企劃靈感 Project

  • 已指定 projectId
  • 可由企劃成員整理、依權限共享
  • 不代表公開頁內容

同一筆靈感只有一個主要 ownership，不複製成兩筆失同步。「我的靈感」加入企劃時＝指派 projectId 或建立與 Project 的關聯（此 ownership 決策仍需本地確認）。

Contract Status

需本地確認
DOMAIN CONTRACT NEEDS DECISION
需本地確認：① InspirationItem 是 account-owned／project-owned／account-owned + optional project context（原型採後者）；② EntityLink 是否擴充支援 inspiration type；③ Project shared inspiration 的 membership／permission；④ 轉換紀錄只用 EntityLink 或另有 conversion metadata。
4C.1 交接 · Ownership 改 ownerType+ownerId
正式概念：InspirationItem.ownerType: user|project + ownerId，分享走獨立 InspirationProjectLink{inspirationId, projectId, visibility, status}。個人靈感仍由 user 擁有、分享不改 ownership、一筆可分享多企劃、企劃共建可由 project 擁有；Host 管企劃靈感 ≠ 能管成員未分享的私人靈感。
4C.1 交接 · converted 非互斥 status
status: inbox | organizing | archived；converted 改由轉換紀錄衍生（hasConversions / conversionCount）。「已轉換」篩選來自紀錄，不代表原始靈感不能再編輯或再次轉換。
4C.1 交接 · InspirationConversion 記錄
InspirationConversion{inspirationId, targetType, targetId, mode: create|attach, createdBy, createdAt, status} 承擔完整轉換歷史（一對多、部分失敗、誰何時轉、回看原始）。EntityLink 仍可表 inspired_by／related_to 語意關聯，但不單獨承擔轉換歷史。
4C.1 交接 · Image／Link Preview
圖片沿用 Asset／AssetLink，InspirationItem 不複製圖片 metadata；Link Preview 未來由安全後端 metadata fetch處理，預覽失敗仍保存原始 URL；外部網址／圖片不因產生預覽自動變成使用者擁有的 Asset。
DATA GAP · inspiration 的 EntityLink type
轉換關聯目前以 EntityLink-shaped 物件（sourceType:'inspiration'）表示；若本地 EntityLink 尚未支援 inspiration type，需擴充——不自建第二套不相容 Link。
API STATUS · NOT IMPLEMENTED
本地正式 Inspiration API、D1 CRUD、Repository、roundtrip 尚未完成。本輪全為 Demo，不暗示可直接接線。
