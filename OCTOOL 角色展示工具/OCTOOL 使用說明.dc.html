OCTOOL 角色展示工具

建立、編輯、展示你的原創角色（OC）設定集。資料存在本機瀏覽器、自動儲存，不需登入。整體流程刻意收斂成兩步：編輯內容 → 設計外觀，預覽是兩者共用的狀態。

一、頂層架構
編輯資料
填角色的所有內容（資料結構）。
模板與展示
把內容排成版面，可「編輯／預覽」切換，並全螢幕展示。
UIUX：刻意只留兩步。早期重複的「展示預覽」頁已合併成模板頁裡的「編輯／預覽」開關。
二、編輯資料

四個子分頁（橫向排列，手機可滑動）：

基礎名稱、頭像、主視覺、標語、主題色
圖設定官方設定相簿，可在圖上「標記」說明
文設定自由區塊與欄位（人設、背景故事等）
圖庫作品相簿，可「關聯」到某套設定
關鍵 UIUX
  • 「歸在分頁」：區塊歸在文／圖設定，只是編輯歸檔，不影響展示。
  • 圖片三分類用視覺區隔（官方設定／作品／主視覺），不靠長文字解釋。
  • 自動儲存只呈現狀態文字，不做成假按鈕；右側即時預覽（手機自動收起）。
三、模板與展示

模板＝一套版面。可建多套、名稱自訂（如「名片」「完整設定」「委託資料」），每套用「積木」堆成。提供「編輯／預覽」切換與全螢幕展示（內建圓點＋箭頭＋頁碼導覽）。

名片 設定集 介紹這隻OC 企劃介紹 paro／AU 圖集 全部積木 空白
四、積木：通用樣式

積木是組成模板的最小單位，共 17 種（下兩頁逐一列出）。多數積木都共用以下調整項，選取後在「元件樣式」面板設定：

寬度整欄 full ／ 半欄 half ／ ⅓ third。各佔一排，並排要用「佈局」積木。
對齊靠左 ／ 置中 ／ 靠右（窄於整欄時用 margin 真正置中）。
效果無 ／ 柔影 ／ 浮起 ／ 光暈 ／ 玻璃（陰影、發光、毛玻璃質感）。
自訂外觀透明度、圓角、自訂底色／文字色／外框。支援積木：標題、標語、區塊、配色、相簿、文字、頭像、主視覺。
內距每個積木的上下左右留白（padding）。
記號說明：⟲ 自動帶入＝內容取自「編輯資料」，改資料就會同步；✎ 自由輸入＝直接在積木上打字；⛶ 可滿版＝能撐到整個畫面左右到邊。
積木參考 ① 自動帶入角色資料

這些積木的內容來自「編輯資料」，只負責「怎麼呈現」，不重複輸入文字。

名稱heading⟲ 自動帶入
取角色名稱，楷體大標。尺寸 sm／md／lg／xl ＝ 26／32／40／50px。預設置中。
一句話tagline⟲ 自動帶入
取角色標語，斜體、加「」引號。尺寸 sm～xl ＝ 16／19／23／28px。
頭像avatar⟲ 自動帶入
圓形頭像。尺寸 sm／md／lg／xl ＝ 76／108／140／180px。無圖時顯示名稱首字。展示時可點開放大。
主視覺cover⟲ 自動帶入　⛶ 可滿版
大圖。寬度 sm～xl ＝ 55／78／92／100%。比例：原圖／橫幅 21:9／寬 16:9／標準 4:3／方形 1:1。預設圓角 16。
區塊section⟲ 自動帶入
綁定一個資料區塊（sourceId）。版式：清單 ／ 卡片。欄位型態自動套對應樣式——長文、標籤雲、屬性表（鍵：值）、物件卡（圖＋名＋註）、✓ 喜好（綠）、✕ 雷點（紅）、一般鍵值。可隱藏標題或覆寫標題。
配色palette⟲ 自動帶入
取角色色票。三種樣式：色卡（色塊＋名稱＋色碼）／色條（連續色帶）／圓點。
相簿album⟲ 自動帶入
綁定一本相簿。版式：格狀（可設欄數與比例）／輪播。展示時點圖可放大看標註。
積木參考 ② 自由內容

直接在積木上輸入內容，與角色資料無關。

標籤badges✎ 自由輸入
一組標籤，每顆可單獨設顏色。樣式：實心 ／ 外框。
小視窗popup✎ 自由輸入
點擊開啟彈窗，放隱藏設定（二設、雷點、條件等）。觸發樣式：按鈕 ／ 縮圖。含標題、內文、可選配圖。
文字text✎ 自由輸入
自由段落，保留換行。尺寸 sm～xl ＝ 14／15.5／18／22px。
跑馬燈marquee✎ 自由輸入　⛶ 可滿版
文字無縫橫向捲動。速度：慢 28s ／ 中 18s ／ 快 10s。可設底色、文字色、圓角；滿版時變整頁橫幅。
按鈕button✎ 自由輸入
膠囊狀視覺元素（裝飾用，非連結）。可設文字、圓角、底色、文字色、外框。
積木參考 ③ 結構與排版

不放內容，負責版面結構。

佈局columns
唯一能讓積木並排的容器。2～3 欄，欄寬可拖曳調整，垂直對齊上／中／下。把其他積木拖進欄位裡。手機自動疊成單欄。
分隔線divider⛶ 可滿版
水平線。可設顏色、粗細、線型（實線／虛線／點線／雙線）。
間距spacer
純空白，用內距控制高度（預設 36px），調節區塊之間的呼吸感。
分頁pagebreak
把模板切成「頁」。驅動全螢幕翻頁、頁面導覽列、以及固定一屏的分頁。
導覽條nav
手動跳頁列，列出各頁、點了可跳。若開了全域「頁面導覽列」，此積木展示時自動隱藏。
五、排版輔助
首屏輔助線畫出每一屏邊界（第2屏、第3屏…），看內容跨幾屏。
每頁高度固定一屏 ／ 自動高度。固定一屏超出時，提供 ✂ 一鍵「自動分頁這頁」。
頁面導覽列全域開關，多頁時自動產生跳頁列（開啟時自動隱藏手動導覽積木）。
六、手機編輯
  • 工具列橫向滑動，不擠成多排，點擊區 ≥42px。
  • 點積木 → 底部小工具列（上移／下移／複製／刪除／樣式／✕），不會亂跳整個面板。
  • 排序用按鈕、免拖曳；右下角浮動鈕「＋積木／設計」。
  • 手機開啟時自動預設「手機」裝置——你排的就是手機看到的版面。
七、視覺風格

奶油暖色系搭配多組主題色，中文字型用霞鶩文楷／思源宋黑，圓角卡片、柔和陰影。色彩集中管理，換主題一鍵套用。

#fffdf8 卡片
#c98a5e 強調
#4a3f35 文字
八、開啟與保存
  • 專案含三個互相連動的檔：OCTOOL.dc.html、TemplateCanvas.dc.html、support.js——請保持同一層、勿改名。
  • 用本機伺服器開啟（不要直接 file:// 雙擊）：於資料夾執行 python3 -m http.server，瀏覽 localhost:8000/OCTOOL.dc.html。
  • 所有角色資料存在該裝置的瀏覽器，會自動儲存。換裝置請用內建的「備份與格式」匯出／匯入。
九、互動細節（UIUX）

這些是讓編輯「順手」的小規則，復刻時別漏。

加入積木的位置
選取某個積木時，新加的積木會插入在它的正下方（不是丟到最底部）；加入後自動選取新積木並切回「設計」分頁，可立刻調樣式。沒有選取任何積木時，才加到模板最底部。面板會即時顯示提示文字告訴你會加在哪。
選取與取消
點積木＝選取，右側面板切到「元件樣式」即時編輯；點畫布空白處＝取消選取，面板回到「全域網站設計」。
排序與微調
拖曳積木左側把手可調順序；面板也有上移／下移按鈕（手機免拖曳）。每個積木都能一鍵複製或刪除——刪除鈕平時低調、滑過才轉紅，避免誤觸。
即時同步與自動儲存
改「編輯資料」的內容，所有引用該資料的模板會即時更新。所有變更即時存在本機瀏覽器，面板顯示「已自動儲存」狀態（非按鈕）。
寬度 ≠ 並排
把積木設窄（半欄／⅓）只是讓它變窄、仍各佔一排，並依對齊靠左／中／右擺放。真正要並排，請用「佈局」積木把元件放進同一列。
預覽與展示
模板頁可切「編輯／預覽」；全螢幕展示內建圓點、箭頭與鍵盤翻頁。有分頁積木時可開「頁面導覽列」自動產生跳頁列。
附錄 · 資料模型

想完整復刻時的資料結構。全部存在瀏覽器 localStorage（主資料鍵 octool:v3、欄位模板 octool:forms）。

① 角色 character
character = {
  name, nickname, tagline,        // 文字
  avatarUrl, mainVisualUrl,       // 頭像、主視覺圖片網址
  palette: [ { id, label, hex } ],          // 色票
  sections: [ {
    id, title,
    group: 'text' | 'image',                // 歸在哪個編輯分頁
    fields: [ { id, label, type, value } ]
  } ],
  albums: [ {
    id, name,
    kind: 'gallery' | 'ref',                // 作品 / 設定相簿
    images: [ { id, url, caption, annotations: [] } ]
  } ]
}
② 欄位型態 field.type
text 單行 longtext 長文 tags 標籤雲 attr 屬性表（鍵：值） object 物件卡（名｜圖｜註） check ✓ 喜好 avoid ✕ 雷點
③ 模板 template
template = {
  name,                                     // 自訂（名片／委託資料…）
  design: { bg, primary, font, width,
            pageFit, autoNav, bgImage … },   // 全域外觀
  blocks: [ {
    id, type,                               // 17 種積木之一
    style: { width, align, fx, opacity,
             radius, bgColor, fullBleed … },
    …type-specific                          // sourceId / text / speed / tags…
  } ]
}
④ 欄位模板 form（只存結構、不含內容）
form = {
  id, name,
  sections: [ { title, group, fields: [ { label, type } ] } ]
}   // 可在「備份與格式」匯出／匯入，套到不同角色
關係：section / album 積木用 sourceId 綁定 character 裡的 section / album——所以同一份資料可被多套模板重複取用，改資料即時同步到所有模板。
