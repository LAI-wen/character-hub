## 1. 已確認 Bug

### B1 — 🔴 P1「加入積木」在沒有模板時是死的

- 角色尚未建立任何模板時，「模板與展示 → 加入積木」面板照常顯示、每顆積木都可點，**點下去完全沒反應**——沒有提示、沒有錯誤、畫布不變。
- 正確流程是**先點「＋模板」建立起始版型**，才能加積木。
- 初次使用者幾乎必然誤判成功能壞掉。
- **建議**：沒有模板時禁用積木面板 / 自動跳「建立新模板」/ 加行內提示「請先建立模板」。

### B2 — 🟠 P1 公開網址 slug 空白時 fallback 成亂碼

- Slug 由「羅馬拼音 Romaji / 代稱」欄位產生：填了 → 漂亮（`/c/shirakiri-akira`）；沒填 → fallback 成 `/c/character-0c6bf5c9`。
- 企劃相同：常夜國 → `/p/JOUYAKOKU`，好山好水 → `/p/PROJECT-4C1F6072`。
- 「小羊」剛好沒填 Romaji，拿到了醜網址，但她是最該被分享的角色。
- **補充**：`/settings` 的「使用者代號變更」目前未開放，使用者**無法自行修改公開網址代號**，與本 Bug 相關。
- **建議**：設為公開但 slug 空白時，提示補填或用名字自動產生，不要無聲 fallback。
